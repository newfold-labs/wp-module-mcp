# Overview

**wp-module-mcp** provides WordPress MCP (Model Context Protocol) integration for Newfold Labs BLU. It registers with the Newfold Module Loader and depends on wordpress/mcp-adapter, wordpress/abilities-api, and firebase/php-jwt. PHP 8.1+. Maintained by Newfold Labs. Distributed via Newfold Satis.
